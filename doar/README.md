# Página de apoio SaYuuVT

Página estática com identidade visual do site existente. Nenhum SDK financeiro ou segredo de API é distribuído ao navegador. Fora de loopback, o gateway está desabilitado por padrão. Sua habilitação depende de configuração e autorizações específicas de publicação e pagamentos.

O formulário usa centavos, apelido público, mensagem, voz permitida, e-mail para processamento e consentimento. Não solicita CPF. Dados sensíveis não ficam em localStorage. A confirmação vem exclusivamente da API; pagamento confirmado e moderação da mensagem são etapas separadas.

Checkout externo oficial é o caminho padrão. QR incorporado está preparado para uso sujeito à revisão da política do GitHub Pages. Nenhum endereço simulado gera Pix utilizável.

Testes automatizados de navegador e gateway pertencem ao repositório privado StreamController; incluem viewport mobile, validação, reconciliação simulada e ausência de caminhos administrativos. Não equivalem a validação financeira real. Esta branch não foi publicada.
